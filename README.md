# 差は静止していない — 個人用 PWA

やる気が出ない朝に開くための「一言集」。スマホのホーム画面から
アプリとして開く。サーバーなし、ビルドなし、素の HTML/CSS/JS。

アプリ本体は **`e09e207c9c/`** の下にある（URL を推測されにくくするための
ランダムなディレクトリ名。中身は個人的なので検索避けに `noindex` も入れてある）。

```
e09e207c9c/
  index.html            画面
  app.css               見た目
  app.js                ロジック（保存・追加/編集/削除・抽選・AI生成・書き出し）
  seed.js               初期データ 17 本
  manifest.webmanifest  PWA マニフェスト
  sw.js                 Service Worker（オフライン）
  icons/                192 / 512 / maskable / apple-touch / favicon
```

## できること

| | |
|---|---|
| 一覧 | 節ごとにグルーピングして表示。タップで編集シートが開く |
| 追加・編集・削除 | 画面下のボタンから。全部ボトムシートなので片手で完結する |
| 節の管理 | 追加・並べ替え・名前の変更・削除（メニュー → 節の管理） |
| 今日の一本を引く | 全一言からランダムに 1 本を全画面表示。直前と同じものは出ない |
| AIで追加 | Claude に 4 件つくらせて、選んだものだけ保存（自動保存はしない） |
| 書き出し / 読み込み | JSON。機種変更のときはこれで移す。「追加」と「置き換え」の 2 通り |
| オフライン | AI生成以外は全部オフラインで動く |

保存先は端末のブラウザの localStorage（キー `pl.data.v1`）。
**アプリやブラウザのデータを消すと消える**ので、たまに JSON を書き出しておくこと。

## AIで追加について

- APIキーは 設定 から入れる。端末のブラウザにだけ保存され、書き出す JSON には含まれない。
- 通信はブラウザから直接 `api.anthropic.com` に送られる（`anthropic-dangerous-direct-browser-access` を使用）。
  サーバーを経由しないかわりに、**キーは端末に置かれる**という前提で使う。共用端末では入れないこと。
- 既定モデルは Claude Opus 5。設定で Sonnet 5 / Haiku 4.5 に落とせる。
- 生成プロンプトは `app.js` の `SYSTEM_BASE`。節の一覧はそのときの実データから差し込まれる。
- 4 件生成して、タップで採用したものだけ保存する。

## GitHub Pages に出す

このリポジトリの Settings → Pages で、**Source: Deploy from a branch**、
**Branch: `claude/motivation-pwa-app-tdre7i` / `(root)`** を選んで Save。
1〜2 分でこの URL に出る。

```
https://<ユーザー名>.github.io/<リポジトリ名>/e09e207c9c/
```

ルート直下には何も置いていないので、`/e09e207c9c/` を知らないと開けない。
（公開リポジトリなら中身は見えるので、「見られて困るもの」は置かない前提。）

### iPhone でホーム画面に置く

Safari で上の URL を開く → 共有 → 「ホーム画面に追加」。
アイコンとして入り、standalone（アドレスバーなし）で開く。
一度オンラインで開いておけば、その後はオフラインでも起動する。
フォント（Shippori Mincho B1 / Zen Kaku Gothic New）も初回に焼き付く。

## 更新するとき

`sw.js` の先頭の `VERSION` を上げてから push する。上げないと古いキャッシュが残る。
