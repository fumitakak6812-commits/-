# 五星麻雀 — GOSEI

5人打ちの麻雀。牌が普通ではなく、演出が過剰。
サーバーなし・ビルドなし・素の HTML/CSS/JS。画像も音声ファイルも使っていない
（牌は CSS で描き、音は WebAudio で合成している）。

```
gosei/
  index.html            画面
  style.css             見た目と演出
  js/rules.js           牌の定義・和了判定・向聴数・役・点数
  js/tiles.js           牌の描画（DOM + CSS）
  js/fx.js              演出（カットイン・パーティクル・画面効果・合成音）
  js/ai.js              対局相手の思考
  js/game.js            進行と画面の更新
  manifest.webmanifest  PWA マニフェスト
  sw.js                 Service Worker（オフライン）
  icons/                192 / 512 / maskable / apple-touch / favicon
```

## 普通の麻雀と違うところ

### 1. 5人打ち

5つ目の風「**星**」がある。自風は **東・南・西・北・星**。
場風は常に東で、東風戦5局を打つと親が一周する。持ち点 25000。

### 2. 4つ目の数牌「星子」

萬子・筒子・索子に加えて **星子（★の1〜9）** がある。
字牌は5風＋白發中の8種。合わせて **44種 × 4枚 = 176枚**。

数牌が4種類になったので三色まわりの役が変わる。

| 役 | | |
|---|---|---|
| 三色同順 | 2飜 | 4種のうち**3種**で同じ並び |
| **四色同順** | **役満** | 4種**すべて**で同じ並び |

### 3. ドラがそのままワイルド ——「変化牌」

各局のドラ表示牌の次の牌が **変化牌**。ドラ1枚ぶんの価値がありつつ、
**どの牌としても使える**。手の中に来ると急に手が近くなる。
カンでめくれたドラは普通のドラで、変化牌にはならない（変化牌は常に1種4枚）。

この1点でゲームの手触りがかなり変わる。手が入らないまま流局する退屈さが減り、
派手な手が出やすくなる。実際に打たせて数えると、和了率がおよそ **23% → 70%** になる
（鳴き・立直なしで回した簡易シミュレーション。`node` でルールだけ動かせる）。

### この麻雀だけの役満

| 役満 | 内容 |
|---|---|
| 四色同順 | 同じ並びの順子を4種類の数牌すべてで |
| 五風連合 | 風牌の刻子4つ＋残る風の雀頭（ちょうど14枚） |
| 星一色 | 星子と字牌の「星」だけ |
| 無双 | 幺九16種のうち14種を1枚ずつ（この麻雀の国士無双） |

ほかに四暗刻・大三元・字一色・清老頭も入っている。

## 演出

- **立直** — 画面が青く閃光、集中線、シェイク、「立直」のスラムカットイン
- **ロン / ツモ** — フラッシュ、放射状の集中線、パーティクル、カットイン
- **役満** — 金の集中線と星の雨、銅鑼、シャインする「役満」カットイン
- **結果画面** — 役が1つずつ出て、最後に点数がカウントアップする
- **変化牌** — 手牌の中で金と紫に明滅する
- 音はすべて WebAudio の合成。牌の音はノイズ＋バンドパス、銅鑼は倍音の重ね合わせ。

右上のボタンで速度（×1 / ×2 / ×3）と消音を切り替えられる。

## 簡略化していること

- 点数は**符を使わない**。1飜1000点／2飜2000／3飜3900／4飜以上は満貫8000…役満32000、親は1.5倍。
- ツモは「親が半分、子が1/6ずつ」で割る。
- 親は必ず流れる（連荘なし）。流局で本場だけ増える。
- 振聴は自分の河と、ロンを見逃したときの同巡振聴まで。
- 平和は「門前・全部順子・雀頭が役牌でない」で判定（待ちの形は見ていない）。
- ダブロンあり。供託は放銃者から近い和了者が総取り。

## 動かす

素の静的ファイルなので、このディレクトリを配信するだけでいい。

```
npx http-server -p 8080 .    # → http://localhost:8080/gosei/
```

GitHub Pages に出しているなら
`https://<ユーザー名>.github.io/<リポジトリ名>/gosei/` で開く。
iPhone なら Safari で開いて「ホーム画面に追加」。一度オンラインで開けば、
あとはオフラインでも起動する。

## 更新するとき

`sw.js` の先頭の `VERSION` を上げてから push する。
